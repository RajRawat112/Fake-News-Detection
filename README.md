# 📰 Fake News Detection System  

A **machine learning web application** that detects fake news articles using **Natural Language Processing (NLP)** and **Logistic Regression**.  

![Python](https://img.shields.io/badge/Python-3.8%2B-blue)
![scikit-learn](https://img.shields.io/badge/scikit--learn-ML-orange)
![Dash](https://img.shields.io/badge/Web%20App-Dash%20%26%20Plotly-brightgreen)
![Accuracy](https://img.shields.io/badge/Accuracy-98.94%25-success)
![License](https://img.shields.io/badge/License-MIT-lightgrey)

---

## 🚀 Features  
- 🧠 **Real-time fake news detection**  
- 📊 **Interactive web dashboard** built with Dash & Plotly  
- ✅ **98.94% prediction accuracy**  
- 🎯 **Confidence scoring** for predictions  
- 🕒 **Prediction history tracking**  

---

## 🧩 Demo  

Paste any news article into the dashboard to instantly receive:  
- **Prediction:** Real 🟩 or Fake 🟥  
- **Confidence score**  
- **Text statistics (word count, sentiment, etc.)**

> Example output:
> ```
> Prediction: FAKE
> Confidence: 96.7%
> Words: 520 | Sentiment: Neutral
> ```

---

## 🗂️ Dataset  
- **Source:** [Kaggle Fake and Real News Dataset](https://www.kaggle.com/clmentbisaillon/fake-and-real-news-dataset)  
- **Size:** 44,898 articles  
- **Split:** 50% Real News / 50% Fake News
